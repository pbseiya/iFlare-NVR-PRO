# Explainer Video Materials

This folder contains assets for creating the final project explainer video.

## Files
1.  **project_explainer_th.mp4**:
    - The main walkthrough video demonstrating the Dashboard, Cameras, and Recordings flow.
    - Duration: ~1 minute.

2.  **project_explainer_th_detailed.srt**:
    - Detailed Thai subtitles synchronized for a voiceover.
    - Includes sections marked generally and sections marked for the "supplementary" detailed view.

3.  **images/**:
    - Contains high-resolution screenshots to be used as static overlays for the "Detailed/Supplementary" sections of the script, since the video recording for these specific interactions (Zoom clicks) could not be captured due to tool limitations.
    - `recordings_page_zoom_example.png`: Shows the timeline at high zoom level (5m) with coloring.
    - `cameras_page_example.png`: Shows the cameras grid view.

## Recommendation
Use `project_explainer_th.mp4` as the base. When the script mentions the "Detailed" features (Zoom/Colors), overlay the screenshot `recordings_page_zoom_example.png` to illustrate the point clearly without needing a moving video for that specific split-second interaction.
